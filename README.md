# PDFAI

## First-time setup (once)
Android native files (Gradle, manifest, icons) are generated by Flutter. In an empty folder run:

    flutter create --org com.aipdf --project-name app --platforms android .

This creates package `com.aipdf.app`. Then copy this project's files over it
(lib/, assets/, docs/, pubspec.yaml, analysis_options.yaml, PROJECT_INFO.txt,
CHANGELOG.md, .gitignore, README.md), replacing the generated lib/ and pubspec.yaml. Then:

    flutter pub get
    flutter run

Never change the package name after it is approved.

## Build notes (stage 3)
pdfrx compiles a small native library: install the NDK and CMake from
Android Studio > SDK Manager > SDK Tools before the first build.
After `flutter pub get`, check the pdfrx version in pubspec.lock and tell Claude if a build error mentions pdfrx.

## OCR models (stage 4) - required once
Download these two files from https://github.com/tesseract-ocr/tessdata_fast (folder root)
and place them in assets/tessdata/ :
  ara.traineddata
  eng.traineddata
(tessdata_fast = small and quick, good for mid/low-end phones. tessdata_best is more accurate but slower and larger.)
